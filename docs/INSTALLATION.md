# Installation

## VSIX

1. Open VS Code.
2. Run `Extensions: Install from VSIX...`.
3. Select `release/codebender-0.6.0.vsix`.
4. Reload VS Code if requested.

CLI:

```bash
code --install-extension release/codebender-0.6.0.vsix
```

Open the **CodeBender** activity-bar icon and start a review session.

## Previous local builds

If `Claude Change Review` 0.5.x is still installed, follow `MIGRATION.md`.
